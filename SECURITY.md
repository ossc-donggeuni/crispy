# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Crispy, please do not report it through a public GitHub Issue or Discussion.

Please use GitHub's private vulnerability reporting feature to report security issues privately.

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation, if available

We will review security reports as soon as possible and coordinate a fix before public disclosure.

## Scope

Security issues may include, but are not limited to:

- Arbitrary command execution
- Unsafe filesystem access
- Path traversal
- Credential or secret exposure
- Improper handling of agent or CLI processes
- Vulnerabilities affecting the VS Code Extension Host or Webview boundary
