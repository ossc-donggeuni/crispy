이 프로젝트에서 환경 설정을 다루는 방식을 조금 더 안전하고 이해하기 쉽게 정리하고 싶어요.

현재 `src/config.ts` 안에 기본값, 환경 변수 읽기, 값 변환 로직이 한꺼번에 들어 있습니다. 이 파일을 수정해서 `PORT`는 숫자로 안전하게 변환하고 사용할 수 없는 값이 들어오면 원인을 알 수 있는 오류를 보여 주세요. `LOG_LEVEL`은 프로젝트에서 지원하는 값만 받을 수 있게 해 주세요. 기본 설정값은 새 `src/configDefaults.ts` 파일로 분리해서 다른 코드에서도 같은 값을 사용할 수 있으면 좋겠습니다.

설정 구조가 바뀌면 실제로 설정을 사용하는 코드와 관련 테스트가 어떤 영향을 받는지도 함께 살펴봐 주세요. `README.md`에는 지원하는 환경 변수, 기본값, 잘못된 값을 입력했을 때의 동작을 설명하는 사용 방법을 추가하고, 이제 내용이 맞지 않는 `docs/legacy-config.md`는 제거하려고 합니다. 현재 테스트 구성과 package script를 확인해서 어떤 테스트를 보완해야 하는지도 계획에 포함해 주세요.

기존 실행 동작을 불필요하게 바꾸지 않으면서 위 작업을 구현하려면 어떤 파일을 어떤 순서로 다뤄야 하는지, 구현 전에 확인할 점과 구현 후 비교할 기준까지 포함한 구체적인 작업 계획을 작성해 주세요.
